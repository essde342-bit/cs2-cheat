# 🌌 Void DLC: CS2 External

**Абсолютный контроль. Нулевая заметность.**

Высокопроизводительный внешний (external) ESP-чит для Counter-Strike 2, разработанный с упором на безопасность, стабильность и минималистичный дизайн. Никаких инъекций, никаких уязвимых драйверов — только чистое чтение памяти и математически выверенный DirectX 11 рендер поверх игрового окна.

#### ⚡ Ключевые особенности
- 🛡️ **100% External Architecture:** Работает без внедрения в процесс игры, что сводит риск обнаружения к минимуму.
- 🚀 **Custom Loader:** Весь payload и графические ресурсы зашиты внутрь одного исполняемого файла. Никаких лишних файлов рядом.
- 🎨 **ImGui Overlay:** Плавный рендер с частотой 60+ FPS, не нагружающий систему.
- 📐 **Продвинутый ESP:** 
  - Настраиваемые рамки (Box) с выбором цвета и толщины.
  - Скелетная визуализация (Skeleton) на основе актуальных структур `CGameSceneNode`.
  - Индикатор здоровья (HP Bar) и текстовое значение (HP Text).
  - Линии притяжения (Snaplines) с фильтрацией по дистанции.
- ⚙️ **Умная фильтрация:** Возможность скрытия союзников и ограничение дальности прорисовки для снижения визуального шума.

#### 🎮 Управление
- `INSERT` — Открыть/закрыть меню настроек.
- Меню полностью интерактивно: при открытии мышь взаимодействует с читом, при закрытии — клики проходят сквозь оверлей прямо в игру.

> **Требование:** Игра должна быть запущена в оконном или безрамочном режиме (`-windowed -noborder`).
